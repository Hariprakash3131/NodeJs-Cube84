Quick Start & Installation

Servora utilizes Node.js and Vite for ultra-fast local development and minified production builds.

# 1. Clone or extract the project directory

cd servora

# 2. Install dependencies

npm install

# 3. Start local development server (with HMR & live reload)

npm run dev

# 4. Compile minified production bundle into /dist

npm run build

Customizing Brand Colors

All theme colors are declared as CSS variable RGB triplets in src/css/main.css. This allows full Tailwind alpha opacity support (e.g. bg-primary-500/20).

To change your primary brand color, update the :root variables in src/css/main.css: 

:root {
  /* Default Primary: Indigo RGB values */
  --primary-500: 99 102 241;
  --primary-600: 79 70 229;
  /* Secondary: Cyan RGB values */
  --secondary-500: 6 182 212;
}

Dark Mode Architecture

Servora uses class-based dark mode (class="dark" on the root <html> element).

To prevent any Flash of Unstyled Content (FOUC), an inline script in src/partials/meta-head.html evaluates user preference from localStorage and window.matchMedia prior to DOM rendering.

RTL (Right-to-Left) & Arabic Support

Servora is engineered exclusively with Tailwind CSS logical utilities:

  • ms-* and me-* (margin-inline-start / margin-inline-end) instead of ml-* / mr-*
  • ps-* and pe-* (padding-inline-start / padding-inline-end) instead of pl-* / pr-*
  • start-* and end-* instead of left-* / right-*
  • text-start and text-end instead of text-left / text-right

When dir="rtl" is set on <html>, the layout automatically mirrors and loads the Cairo Arabic font stack.

3D WebGL Engine & Performance Rules

The Three.js hero scene in src/js/three-hero.js follows strict enterprise performance standards:

1. IntersectionObserver Pause: WebGL renders only when the canvas container is in the active viewport; it cancels requestAnimationFrame immediately when scrolled out of view.
2. Page Visibility API: Pauses rendering when the user switches browser tabs.
3. Capped DPR: Clamped at Math.min(window.devicePixelRatio, 2) to protect mobile GPUs.
4. Reduced Motion: Respects prefers-reduced-motion by rendering a static fallback.
5. Full Teardown: Disposes of geometries, materials, and renderer contexts on page exit.

Production Deployment

Running npm run build outputs optimized, static production HTML files into dist/.

You can deploy the dist/ directory directly to any static web hosting provider:

  • Vercel: vercel deploy --prod
  • Netlify: Drag and drop the dist/ folder into Netlify Drop.
  • Cloudflare Pages: Set build directory to dist and build command to npm run build.
  • Apache / Nginx / CPanel: Upload the contents of dist/ to public_html.
